# 名建筑拆解 · 质量标准

第 1 集（罗马万神殿，草稿 2，2026-09-29）经用户认可："这个质量就差不多了，以后就按这个标准和流程来"。本文件把那一版的做法写成每集都要达到的标准。完整样例见 `episodes/ep01_pantheon/`。

标准是对标线，不是创作的笼子。下面写的是每集必须过的底线和用户明确否定过的做法；镜头怎么走、先拆哪一块、用什么比喻，按每座建筑自己的看点来定。

---

## 1. 规格

| 项目 | 标准 |
|---|---|
| 画幅 | 竖屏 9:16，1080×1920 |
| 时长 | 约 40 s（30–45 s 可接受） |
| 帧率 | 24 fps，帧 1 = 0.000 s |
| 声音 | 纯配乐，无旁白；公有领域或 CC0 录音；响度 −14 LUFS（`kit/finish.py` 两遍 loudnorm，实测 −13.9） |
| 交付 | `<ep>_final.mp4`（1080×1920 H.264 + AAC 192k）+ `_share.mp4`（1080×1920，两遍 5 Mb/s，40 s 约 26 MB，< 30 MB，发给用户在手机上看）+ 无音乐版 `silent.mp4`（只有静音音轨，用抖音站内配乐时发这一版）+ 联系表 `contact.jpg` |
| 平台 | 抖音 + B 站竖屏，发布走 video-publish-kit |

## 2. 模型

- **外观自建**，真实材质：kit 的程序化 PBR（`realkit.py`：花岗岩、大理石、石灰华、罗马砖、铅皮、青铜、铺地……），不用贴图。按结构分块建模，每一块都能单独拆开、移动、淡出。
- **室内可选真实扫描**，只用在"揭晓"镜头（ep01：镜头钻进天眼后看到的扫描圆厅）。扫描要经过 `import_scan.py`：先在 Blender 外把贴图压到 4K 以下，再缩放对齐到真实尺寸。
- 扫描外观通常不可用（ep01 的外观扫描柱子融化、底部破碎），只作比例参考。
- 画面里的数量要和事实一致：ep01 的 16 根柱、8 根墩柱、5 圈 × 28 格藻井，模型里都按实数建。

## 3. 叙事与画面

1. **开头就是完整、一眼能认出的建筑**，配一句钩子字幕（问题或反常识），例："屹立 1900 年，没用一根钢筋 / 这座穹顶凭什么不塌？"
2. **拆解（爆炸图），不是平地而起。** 建筑从完整状态被拆开：穹顶抬起分层散开、门廊前滑、半边绕铰链转开……再按原路合回。
3. **每一步只揭示一个结构，配一条标注。** 标注 = 主标题 ≤ 14 字 + 副标题 ≤ 22 字，文字事实经过查证（见第 6 节）。
4. **讲作用，不只讲部件。** 观众要看到"它在干什么"：ep01 用金色力线从穹顶底部经砖拱流进 8 根墩柱，而不是在墙上画几道弧线。只画出"有什么"会显得抽象（用户否定过）。
5. **钩子要有回答。** 开头的问题在中段逐项作答，片尾一条顶部字幕收在结论上（ep01："至今最大的无钢筋混凝土穹顶 / 名建筑拆解 01 · 罗马万神殿"）。
6. **镜头一直在动**：环绕、推拉、升降，没有定格死帧。硬切只用于匹配剪辑（ep01：外面的天眼圆洞切到室内仰望的同一个圆洞）。
7. **背景安静但不空**：建筑放在场地里（铺地有磨损变化、石桩、喷泉方尖碑），远处低对比城市剪影融进雾里（episode JSON 的 `setting`）。不能是纯色虚空。
8. **无缝循环**：所有拆解动作在收尾前复原；最后一个镜头关键帧（第 frames+1 帧，不渲染）与第 1 帧完全相同，接缝两侧同向同速环绕；第 960 帧之后接第 1 帧不跳。

## 4. 光影与调色

电影感的光和调色是标准的一部分。光影按集变化：每集从预设库 `kit/light_presets.py` 里挑**一个**适合这座建筑的预设。

- **一集一个预设，从第 1 帧用到最后一帧。** 集内不换预设、不换时段；天空、太阳方向和颜色、调色全片一致。结构图解段可以把主光压暗，让图解颜色读得出（ep01：拱券图解段 `sun_keys` 压到 10 %，出图解的硬切处复原），光影本身不变。
- **按建筑选**：看材质、所处环境、建筑性格和这一集要讲的故事。黄昏不是默认值，只是 ep01 的选择（万神殿：石灰华、罗马砖、花岗岩柱的暖色古典地标，立在城市广场上）。选定的预设和理由写进该集 `SCRIPT.md` 的"模型与材质"。
- **写法**：episode JSON 里 `"real_look": {"preset": "<名字>"}`，建筑确实需要时才覆盖个别键。预设同时带灯光与天空、地面暖石色修正和调色（episode 没写 `grade` 时，`overlay.py` 用预设的调色）。

| 预设 | 名称 | 光 | 适合（例） |
|---|---|---|---|
| `golden_hour` | 黄昏 | 低角度暖阳侧光，偏蓝的天光补光，暖色轮廓光，灰蓝薄雾和云 | 暖色石材、砖、石灰华的古典或历史地标，立在城市广场：万神殿、罗马斗兽场、佛罗伦萨大教堂 |

**护栏**（开渲前拿钩子静帧检查，`kit/preset_stills.py` 或 `run_episode.py --look` 出图）：
1. **建筑和背景分得开**：明度上比身后亮或暗，冷暖上有对比（暖石 / 泛光对蓝天 / 阴影）。建筑沉进天空或地面时改光（曝光、泛光 / 光柱强度、雾量），不靠调色救。
2. **讲解的结构看得清**：标签指着的部位必须受光（夜景给门廊、柱子加低位正面泛光；阴天把光柱对准镜头看到的立面；晨雾用 `mist_top` 让上部清楚）。
3. **地面不偏粉紫，颜色不脏**：红橙太阳加紫色天光会把灰石照成洋红，所以太阳保持黄橙、天光偏蓝不偏紫，保留预设的地面修正和 `hue_fix`；暖石上不蒙灰褐色雾；夜里的石桩、喷泉不能自己发亮。实测一块地面：色相在 20–40°（暖）或 200–230°（蓝），不能在 290–350°。
4. **标注读得清**：顶部字幕和标签卡落在天空带，这一带要安静（字后面没有刺眼的太阳光晕或碎云）；深色天空（夜景）和浅色天空（晨雾）都要带真实字幕检查。

**可选，默认关闭**：蓝图 / X 光图层（`graphics`：X 光剖切、发光线框、地面网格、尺寸线，`kit/blueprint.py`）和蓝图玻璃标签卡（`graphics.card_style`）留在 kit 里作可选功能，不属于标准。episode JSON 不写 `graphics` 就不会出现；标准标签卡是第 5 节的红条卡。

## 5. 标注版式

- 标签卡：左侧红色竖条 + 主标题 62 px + 副标题 44 px（`overlay.py`），太长的主标题可在 `labels.json` 设 `size` 缩小，但优先改短。
- 位置避开正在动的部件，也不压浮起的圈层；各条标签分散在上下左右，不要都挤在左上角。
- **抖音安全区**：底部 20 %（y > 1536）和右侧 12 %（x > 950）不放任何文字；顶部字幕条固定从 y ≈ 190 开始（`overlay.py`），标签卡放在 y 230 以下，不和同时出现的顶部字幕重叠。
- 引线跟着部件走（anchor `follow`），部件出画或被遮挡时标签淡出。

## 6. 事实核查

- 屏上出现的**每一个数字、名字、年份**都要在 `SCRIPT.md` 的事实核对表里有一行：屏上内容 / 核对结论 / 来源 URL 或文献 / 置信度。
- 至少两个可靠来源一致才算"高"；有争议的说法改用更稳妥的措辞（ep01："撑着"改"引向"，"墙是空的"改"墙不是实心的"，年份用区间 118–128 年，高度用 ≈）。
- 需要专门查的结构问题单独写 `FACTS_<主题>.md`（ep01：`FACTS_walls.md`）。
- 结构示意图可以简化，但简化的地方要在 SCRIPT.md 里写明，屏上文字不能涉及被简化掉的细节。
- 严谨只花在屏上出现的内容上；配乐版本等不展示的细节，来源清楚、许可正确即可。

## 7. 技术底线

- **没有闪烁**：不用剖切面（剖切面与模型表面共面会 z-fighting 闪烁）；要"剖开"就让半边绕铰链转开。会分离的部件之间不能有共面（在 builder 里错开 3–6 cm）。嵌套的壳用同样的位移或同一个铰链移动，外壳永远不穿过内壳。
- **一套色彩管理**：全片一个 view transform（AgX，对比档跟光影预设走，多数预设是 Medium High Contrast）；扫描贴图经逆 AgX LUT 显示得和 Standard 一样（`realkit.load_scan` 自动处理），外景与扫描室内之间切换不跳色。
- 首帧与循环接缝逐像素检查；关键段逐帧看有无闪烁、穿模、发白。
- 草稿 540×960 审片，定稿 1080×1920 只渲一次。

## 8. 教训（用户否定过的，或踩过的坑）

| 教训 | 由来 |
|---|---|
| 纸模质感被否定，改真实材质 | ep01 纸模草稿："纸模质感差，要换成真实建筑" |
| 平地而起不如拆解 | ep01 纸模草稿：用户觉得"把原本的建筑拆解"更好看 |
| 画在表面的细节显得抽象 | ep01 草稿 1：砖拱只是墙上的弧线，用户说太抽象 → 做成立体楔形砖拱 + 空腔 + 力线 |
| 剖切面会闪 | ep01 纸模草稿：展示球时左侧闪烁（剖切面与纸面共面） |
| 8K 贴图不能进 Blender | 8 GB 内存：先用 `import_scan.py downscale` 在 Blender 外压到 4K，Blender 里再降到 2K |
| 一次只开一个 Blender | 8 GB 内存：所有 Blender 走 `kit/blender_locked.sh`；多个 agent 同时渲染会把桌面版挤崩 |
| 自建外观优于扫描外观 | ep01：用户看了扫描外观对比后选"还是自建的好" |
| 背景不能空 | ep01：用户要求"稍微调节，不要太空旷" → `setting` |
| 屏上措辞要经得起查 | ep01："1900 年"会被读成年份 → "屹立 1900 年"；"唯一光源" → "唯一天窗" |
