## 2. 模型与材质

- 风格 `real`：程序化 PBR（花岗岩、大理石、石灰华、罗马砖、铅皮穹顶、青铜），AgX Medium High Contrast。
- 光影：`golden_hour`（黄昏），全片一个预设。低角度暖阳从侧面照亮石灰华门廊和砖墙，偏蓝的天光和灰蓝薄雾、云把暖色建筑从背景里托出来。选它是因为万神殿是石灰华、罗马砖、花岗岩柱的暖色古典地标，立在城市广场上。地面用暖石色（`real_palette`）+ 调色 `hue_fix`，不偏粉紫；拱券图解段（20.3–27.0 s）主光压到 10 %（`sun_keys`），让橙色砖拱和金色力线压过正面受光的鼓墙，出图解的硬切处复原。调色（`grade`）在扫描室内段（12.375–15.0 s）关掉 `hue_fix` 和 `shadow_cool`，扫描保持原色。
- 室内是摄影测量扫描（`scan`），经逆 AgX LUT 显示成与定稿静帧 `out/lookdev_real/interior_scan.png` 一致的颜色。
- 墙体结构图（`build_pantheon._wall_diagram`，只在 20.45–26.95 s 显示，替换鼓墙的混凝土内芯）：
  - 8 根墩柱（每根占 18°，灰色混凝土，受力时从上往下变金色）；
  - 8 个开间（入口 + 7 个大龛），每个开间三层拱顶空腔，内衬深色，始终保持黑色；
  - 每层一道砖拱：15 块立砌楔形砖（橙红罗马砖），拱圈厚 1.4 m，贯穿墙厚，拱脚落在墩柱上；
  - 金色力线（每开间每层左右两股，共 48 股）和箭头；穹顶底部金色光环。
- 外皮"幽灵"：所有 `realkit` 材质读对象属性 `pk_ghost`（0 = 不透明，1 = 完全透明）。

## 5. 配乐

巴赫《G 弦上的咏叹调》BWV 1068，United States Air Force Band — Air Force Strings（公有领域，美国政府作品），文件 `music/bach_air_usaf.mp3`（来源页 https://commons.wikimedia.org/wiki/File:Air_-_Air_Force_Strings_-_United_States_Air_Force_Band.mp3 ）。从 4.2 s 起截 40 s，0.3 s 淡入，37.3–40.0 s 淡出，响度 −14 LUFS：

```bash
ffmpeg -i <video> -ss 4.2 -t 40 -i music/bach_air_usaf.mp3 \
  -filter_complex "[1:a]afade=t=in:st=0:d=0.3,afade=t=out:st=37.3:d=2.7,loudnorm=I=-14:TP=-1.5:LRA=11[a]" \
  -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k -ar 48000 -shortest -movflags +faststart OUT.mp4
```

## 6. 制作命令

在仓库根目录运行（素材取回见 `assets.md`）：

```bash
# 草稿 540×960：锚点 + 960 帧（draft_render：6 samples、shadow_res 0.3、无光追）+ 标签 + 顶部字幕 + 配乐

python3 kit/produce.py episodes/ep01_pantheon/episode.json final     # -> out/ep01_final.mp4、_share.mp4
```
